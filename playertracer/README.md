# Player Tracer (Fabric 1.21.11)

* **Right Shift** (rebindable) opens a menu listing the players around you, nearest first.
* Click a name -> red tracer line + red 3D hitbox wireframe + name/distance label on that player.
* **K** (rebindable) or the "Clear target" button removes it.
* Menu button toggles whether the line starts at the crosshair or the bottom of the screen.

Build: push to GitHub and download the jar from the Actions run, or `./gradlew build` (JDK 21) -> `build/libs/playertracer-1.0.0.jar`.
Needs Fabric Loader + Fabric API for 1.21.11.
